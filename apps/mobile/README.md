# @appq/mobile

React Native CLI application for AppQuest.

See the repository root [README](../../README.md) and [ARCHITECTURE](../../docs/ARCHITECTURE.md).

## Scripts

| Script | Description |
|--------|-------------|
| `yarn start` | Metro bundler |
| `yarn ios` | Run iOS |
| `yarn android` | Run Android |
| `yarn lint` | ESLint |
| `yarn typecheck` | `tsc --noEmit` |
| `yarn test` | Jest |
